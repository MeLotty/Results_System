# Results System — Computer Studies Quiz

A responsive, dependency-free website built with HTML5, CSS3, and vanilla JavaScript.

Open `index.html` in a modern browser, or serve the repository with any static web server. For example, if Python is available:

```sh
cd /workspace/Results_System
python3 -m http.server 8000 --bind 0.0.0.0
```

The quiz includes 10 questions, accessible radio controls, progress tracking, scoring, answer explanations, and a restart option. Answers stay in memory and reset when the page is refreshed. No accounts, database, installation, or build step is needed.

For GitHub Pages, publish this branch from its root directory in the repository's Pages settings.
